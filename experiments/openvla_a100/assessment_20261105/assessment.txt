Interpretation limits:
1. No held-out validation split: overfitting and generalization cannot be assessed.
2. Accuracy is exact token agreement, not successful pickup/carry/release rate.
3. Teacher forcing can be optimistic versus autoregressive live execution.
4. Joint MAE compares decoded quantized labels; it is not TCP error in millimetres
   and does not include all quantization/clipping error against raw actions.
5. Gripper predictions do not measure force, contact, retention or closing timing.
6. Only the original orange-cube instruction was represented in this training set.
   This run provides no measured evidence for blue cubes, fruit sorting or two-object tasks.
7. Original OpenVLA uses base RGB alone. Camera consistency matters; wrist views
   and measured joints are not model inputs under this recipe.

Recommendation: keep the20,000-step adapter and its pinned base model,
normalization and action contract together. First review free-running predictions
on saved episodes, especially gripper transitions and joint-target jumps; then
perform a separately isolated, slow physical trial with measured task outcomes.
Do not select more training steps merely from decreasing training loss. Use episode-level
held-out evaluation and physical tests to decide whether a later training run is needed.
